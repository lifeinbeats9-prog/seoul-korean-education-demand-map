# Seoul Korean Education Demand Map

This repository is the public static-release mirror for the Project C portfolio application.

The site visualizes the **end-2025 structure of registered foreign residents across Seoul's 25 districts** using public Seoul Data Hub statistics. It supports views by published nationality, grouped-age and stay-status categories and by sex where directly available.

The application **does not directly measure or predict Korean-language learning demand, Korean proficiency, market size, or an individual's educational need**. Separate marginal tables are not combined into synthetic person-level or multidimensional joint distributions.

Public analytical source: Seoul Metropolitan Government Data Hub, KOGL Type 1. Detailed attribution and period labels are displayed in the application.

Development, data-contract governance and audit history are maintained in a separate private canonical repository. This public repository contains only an approved static release payload and its `RELEASE_MANIFEST.json`.

Release identity and file hashes are recorded in `RELEASE_MANIFEST.json` so a published version can be traced to the exact audited canonical source commit.
